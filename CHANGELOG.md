v5.0.0 - 22.05.2026
- Added meter type & unit support (Water, Gas, Electricity, Custom)
  - Type-specific colors and default units shown across cards, charts and HA discovery
  - Meter type persisted in `watermeters` table with migration
- Added daily history: one snapshot per day recorded automatically, never pruned
  - Gap-aware daily average: multi-day gaps correctly weighted by elapsed calendar days
  - Detailed and daily charts in meter view with smart time/date axis labels
- Added consumption stats on meter cards: today's consumption, daily average, yearly estimate
- Added Home Assistant MQTT sensor groups
  - Four sensors per meter (reading, today, daily avg, yearly estimate) grouped under one HA device
  - Type-aware `device_class` and `state_class` per meter type (water/gas/energy)
  - Unique ID prefix matches meter type (watermeter_, gasmeter_, electricitymeter_, custommeter_)
  - Re-publishes registration automatically when meter settings change
- Added image post-processing controls per meter: horizontal flip, brightness, contrast, saturation
  - Flip reverses digit order in display mode; flips individual digits in each-digit mode
  - Sliders only trigger re-evaluation on release (no lag during dragging)
- Added in-app global settings view (MQTT broker, credentials, topic, retention limits)
  - "Fill from Home Assistant" button auto-imports credentials from HA supervisor
- Redesigned navigation topbar with contextual breadcrumb (Overview / Settings / current meter)
  - Mobile: icon-only mode below 600 px
- Fixed `daily_history` not being populated when evaluations are triggered via MQTT
- Fixed MQTT supervisor credentials endpoint not unwrapping the `data` key from supervisor response
- Fixed `dailyAvgConsumption` scaling bug in frontend charts
- Disabled chart animations to prevent lag on slow devices
- Added `services: ["mqtt:need"]` to `config.json` for HA supervisor MQTT access
